What happened

Every move gets a reward from 0 to 1. Amber lines are things the environment did on its own.

    What the agent sees and does

    Each step it gets the backlog, every worker's skills, load and availability, and the budget. It answers with one move: give task X to worker Y.

    How moves are scored

    A valid assignment earns 0.5, plus bonuses for the right skill, high priority, beating a deadline and spreading load. Wrong skill, a busy or absent worker, or a blocked task scores 0.0–0.2.

    Use it from code

    Standard OpenEnv API: POST /reset, POST /step, GET /state, and POST /grade for the official score. Full reference in the API docs.

    Built by Hitesh Firke for the Meta PyTorch OpenEnv Hackathon × Scaler School of Technology. The "baseline agent" is a simple rule-based policy (urgent and high-priority first, least-loaded skilled worker), not a trained model.
